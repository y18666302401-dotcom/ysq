# 实验：画风样张（同一场景，九种画风）

- `styles.html`：浏览器打开，点按钮切换画风，画面持续播放。
- `samples/`：第 3.5 秒的样张，`00_overview.jpg` 是九宫格总览。
- `chars.js`：3/4 侧身的学者和猫（来自 `../three-quarter/`），所有绘制都经过 `fig()`。

画风只改出图方式，造型数据不变：

| 画风 | 做法 |
|---|---|
| ① 描边卡通 | 合并轮廓描边 + 沿轮廓的相乘暗部 |
| ② 扁平插画 | 无描边，暗部是同色系深一档的平涂色块，颗粒纸纹 |
| ③ 逐帧手绘 | 轮廓逐张颤动（jitter），暗部用排线，纸纹 |
| ④ 水彩绘本 | 细淡的线，SVG 湍流位移让边缘晕开，水彩纸纹 |
| ⑤ 水墨 | 颜色换成墨色浓淡，粗墨线，宣纸纹，远山淡墨，竖排题字和印章 |
| ⑥ 美漫网点 | 粗黑线，饱和色，网点暗部，放射线背景，对白气泡 |
| ⑦ 光影剪影 | 角色合成整体剪影，朝向光源的一侧统一算轮廓光 + 光晕，黄昏天空 |
| ⑧ 剪纸拼贴 | 无描边，每层纸带投影，边缘毛糙，牛皮纸纹 |
| ⑨ 像素 | 原尺寸加粗线条绘制 → 缩小 1/5 → 量化到调色板 → 整数倍放大 |

性能：水彩、水墨、剪纸用了 SVG 滤镜，每帧约 5–9 秒；其余每帧不到 0.5 秒。
