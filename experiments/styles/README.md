# 实验：画风样张（同一场景，十八种画风）

- `styles.html`：浏览器打开，点按钮切换画风，画面持续播放。
- `samples/`：第 3.5 秒的样张，`00_overview.jpg`、`00_overview_2.jpg` 是两组九宫格总览。
- `chars.js`：3/4 侧身的学者和猫（来自 `../three-quarter/`），所有绘制都经过 `fig()`。

画风只改出图方式，造型数据不变：

| 画风 | 做法 |
|---|---|
| ① 描边卡通 | 合并轮廓描边 + 沿轮廓的相乘暗部 |
| ② 扁平插画 | 无描边，暗部是同色系深一档的平涂色块，颗粒纸纹 |
| ③ 逐帧手绘 | 轮廓逐张颤动（jitter），暗部用排线，纸纹 |
| ④ 水彩绘本 | 细淡的线，SVG 湍流位移让边缘晕开，水彩纸纹 |
| ⑤ 水墨 | 颜色换成墨色浓淡，粗墨线，宣纸纹，远山淡墨，竖排题字和印章 |
| ⑥ 美漫网点 | 粗黑线，饱和色，网点暗部，放射线背景，对白气泡 |
| ⑦ 光影剪影 | 角色合成整体剪影，朝向光源的一侧统一算轮廓光 + 光晕，黄昏天空 |
| ⑧ 剪纸拼贴 | 无描边，每层纸带投影，边缘毛糙，牛皮纸纹 |
| ⑨ 像素 | 原尺寸加粗线条绘制 → 缩小 1/5 → 量化到调色板 → 整数倍放大 |

第二组：

| 画风 | 做法 |
|---|---|
| ⑩ 日系赛璐璐 | 细的有色线，冷色硬边阴影，受光边留高光，整体柔光 |
| ⑪ 低多边形 | 画面上撒点（颜色交界处密），Delaunay 三角剖分，每个面取平均色并微调明暗 |
| ⑫ 黏土定格 | 每层用 SVG 光照滤镜（漫反射 + 高光）算出圆鼓鼓的体积，带柔和投影 |
| ⑬ 油画厚涂 | 四遍、共约 7 万道短笔触重画，笔触顺着形体边缘，大笔铺色、小笔收边 |
| ⑭ 铅笔素描 | 灰阶，细线抖动 + 一遍淡淡的起稿重影线，排线阴影，纸纹 |
| ⑮ 粉笔黑板 | 粉笔线，淡彩，白色排线阴影，黑板擦痕，手写标题和示意箭头 |
| ⑯ 蓝图 | 白线框，网格，尺寸线、角度标注和图框 |
| ⑰ 木刻版画 | 只有黑、纸色和一种朱红，粗墨线，刻刀排线，边缘毛糙 |
| ⑱ Riso 套色印刷 | 分成荧光粉、蓝、黄三种专色，各自加颗粒、错位套印 |

性能：水彩、水墨、剪纸、木刻每帧约 4–9 秒，黏土约 24 秒；油画、铅笔约 1 秒；其余每帧不到 0.5 秒。
