# 实验：像素风角色设计（测试中）

- `pixel.html`：浏览器打开循环播放 4 秒；`pixel.mp4` 渲染好的视频；`pixel.png` 设计稿截图。
- 角色（原创）：19 世纪的年轻女天文学者，3/4 侧身，抱着黄铜望远镜；下方是 0°/30°/60°/90° 转面图。
- 做法：沿用 `../three-quarter/kit3q.js` 的 3D 截面造型，在 216×384 的像素画布上逐部件硬边光栅化（不抗锯齿），
  每种材质 3 阶限色，按形体偏移出暗部和受光边，前后部件交界画暗线（同组不画），外轮廓 1 像素描边，
  去掉孤立的暗部像素，五官、纽扣、裙褶逐像素点上，最后整数 5 倍放大。动画每秒 8 张。
