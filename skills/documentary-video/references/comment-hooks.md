# 评论钩子：让观众开口

点赞和播放只说明"看完了、觉得不错"；评论要观众**多做一个动作**。观众不评论，通常不是没想法，而是：没人问他、问题太大不知道从哪说、或者说了也没意义。每期都要在**旁白、画面、置顶评论**三处同时给观众一个"张嘴就能答"的理由。

## 1. 什么样的问题有人答

| 好问题（评论多） | 坏问题（没人答） |
|---|---|
| 二选一："换作是你，会拉闸还是继续？" | 开放大问题："你怎么看这件事？" |
| 猜一个数/一个答案："你觉得最后修好花了几年？" | 需要专业知识才能答的问题 |
| 站队：调查结论有真实分歧时，"你信哪种说法？" | 没有立场可站的问题（"是不是很可怕？"） |
| 亲身经历："你家那边遇到过这种天气吗？" | 求赞求关注："觉得好看就点个赞" |
| 挑错 / 补充："还有哪个细节是我没讲到的？" | 一期里问三四个问题 |

**核心标准：观众能在 5 个字以内回答**（"A""会""3 年""第二种"），回答之后还想多说一句理由。

## 2. 每期的钩子配置

每期固定做 **1 个主问题 + 最多 1 个中段预测**，不要多：

1. **开场预告（可选，一句话以内）**：前 10 秒内埋一句，告诉观众结尾有个问题要他回答。例："看到最后，你来判断他到底错没错。" 不能用"你知道吗""今天我们来聊"这类开场白，钩子要接在故事里。
2. **中段预测（可选，放在关键瞬间之前）**：故事走到"下一秒要发生什么 / 他要做什么决定"时，旁白抛一个二选一，画面定格 1–1.5 秒，然后揭晓。例："凌晨 1 点 23 分，值班员有两个选择——停下测试，或者继续。" 观众会在评论里说"我第一时间就猜到了 / 我猜错了"。
3. **结尾主问题（必做）**：替换原来的"有余味的结尾"中的最后一两句，或紧接其后。问题必须从故事里长出来，基于 NOTES.md 里有出处的事实：
   - **反事实决定**：如果当时某个人做了另一个选择，结果会不同吗？
   - **真实争议**：官方结论和另一种有据可查的说法，你信哪个？（只在真的存在分歧时用）
   - **代入**：换作你在那个位置，你会怎么做？
   - **关联经历**：你所在的地方有没有类似的建筑 / 天气 / 隐患？
4. **置顶评论**（发布时，见 07-publish.md）：重复主问题 + 列出选项，再补一条视频里没讲的冷知识。观众进评论区第一眼看到的就是一个可以直接回复的问题。

## 3. 文案写法

- **用纪录片旁白的语气问**，不用营销腔。好："如果那天他没有关掉警报——结局会不同吗？"；坏："家人们觉得呢？评论区扣 1！"
- 旁白**停在问句本身**，问句后面**不加**"评论区告诉我""Let me know in the comments"这类引导（用户 2026-10-12 要求：多余、有营销腔）。告诉观众去评论区答的是画面：提问卡 + 跳一下的评论气泡（见第 4 节），以及置顶评论。问题只说一次。
- 选项要具体，两个选项都要站得住（都有人会选），不要一个明显正确、一个明显愚蠢。
- **尊重遇难者**：不问"猜猜死了多少人"，不拿伤亡做竞猜或站队。问题指向决定、机制、责任、后来的改变。
- 英文版按英语观众习惯改写（"Would you have pulled the lever?"，同样不加 "let me know in the comments"），问题的内容、选项与中文版一致。

## 4. 画面写法

问题不能只在旁白里一闪而过，画面上也要让观众"看见"这是一个等他回答的问题。

- **提问卡**：问题出现的那一刻，画面里出现一张提问卡——按所选画风画成故事世界里的东西（手绘：一张钉上去的纸条 / 档案卡；墨线贴纸：贴纸；扁平：从上一镜色块流进来变成的卡片；柔光：发光的卡片）。卡片上写**问题短句 + A/B 两个选项**（或一个"？"大数字框），文字进 strings.json。
  - 出场有物理原因：被钉上、被拍在桌上、从画面里某个物件翻出来，不淡入。
  - 选项 A/B 用本期标色里能一眼区分的两种颜色。
- **中段预测**：画面定格（主体停在动作半途，环境运动继续，保持"任意暂停测试"），屏幕上出现 A/B 两个选项和一个 3 秒左右的倒计时环或指针，然后镜头继续、揭晓答案，并在已选中的选项上盖一个章 / 打勾。
- **结尾停留**：主问题的提问卡在画面上**至少停 3–4 秒**（旁白结束后继续停留），背景是故事最后一个画面的慢镜头 / 环境运动，配乐收尾但不戛然而止。不要在问题刚问完就黑屏。
- **评论引导图形**：提问卡旁边加一个小的评论气泡图标（按画风画，不用平台 logo），轻轻跳动一次，指向屏幕右下方的评论按钮方向。
- **安全区**：竖屏提问卡放在画面中上部（大约 y 400–1300，x 80–900）。右侧约 180px 宽的竖条（点赞、评论、分享按钮）和底部约 450px（标题、文案）会被平台界面盖住，卡片和选项都不能放进去。
- **字幕**：问题句的关键词（如两个选项）按标色规则变色；提问卡出现时，字幕和卡片不要上下挤在一起。

## 5. 分镜与时长

- 钩子算进 80–90 秒的总时长里，不另加。中段预测约 3–4 秒，结尾问题 + 停留约 5–7 秒；写脚本时相应压缩背景和后果段，不删关键瞬间。
- STORYBOARD.md 里把这些分镜的"画面类型"标为 **互动钩子**，"绘制元素"里写清提问卡的样子、选项文字、出现和停留时长。
- 互动钩子不计入信息画面的 30%–40% 比例。

## 6. 发布后（给用户的建议）

发布后第一小时内，用户亲自回复最早的几条评论（追问理由、给出补充事实），评论区被回复过的视频更容易继续有人评论。可以在 PUBLISH.md 里预备 3–5 条回复模板（针对选 A、选 B、讲自身经历的人）。
