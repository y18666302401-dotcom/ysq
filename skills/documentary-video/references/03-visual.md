# 阶段 3：本期视觉设定

脚本确认后、拆分镜之前，根据这一期的题材和所选画风，设计本期专属的视觉元素。画风文件只规定"怎么画"，本期视觉设定规定"这一期画什么、各代表什么"。

读完 script.md、rules.md 和所选画风文件后，提出下面几项方案。每项给 2–3 个选项并说明理由，由用户选定：

## 1. 路径与关系的标记道具

在地图或关系图上画出路线、联系的道具，要和题材的时代与场景相符。参考：

| 题材 | 可选道具 |
|---|---|
| 航海、探险 | 红线和图钉、航海分规、蘸水钢笔 |
| 战争、战役 | 红蓝铅笔箭头、沙盘小旗 |
| 商业案例 | 白板马克笔、便利贴 |
| 案件、谜团 | 调查墙红线、照片和图钉 |
| 科学发现 | 实验笔记本上的钢笔线和批注 |

## 2. 线条与标记的含义

最多三类，用颜色或线型区分，全片统一，第一次出现时让观众看懂。通用的三类含义：

| 通用含义 | 举例 |
|---|---|
| 实际发生的 | 实际航线 / 公司真实的发展路径 / 嫌疑人实际路线 |
| 原本计划的 | 原定计划 / 当初的战略 / 警方推测的路线 |
| 被动或意外的 | 随浮冰漂流 / 被市场逼出的转型 / 意外出现的线索 |

## 3. 时间计数器

贯穿全片显示时间进度，选最能体现这个故事时间感的形式：日历翻页、"出发第 X 天"、"成立第 X 年"、"失踪第 X 小时"、人物年龄等。

## 4. 调色氛围与色彩脚本

确定本期的主基调，以及随剧情变化的色彩走向（例如：启程温暖 → 困境转冷 → 最低谷最暗 → 结尾透出一丝暖光）。

## 5. 角色设计

列出本期的重要人物（通常 2–3 个）。**设计前先查公有领域的肖像资料**（Wikimedia Commons、Library of Congress、相关机构的档案等），确认真实的发型、胡须、脸型和当时的服装，来源登记到 assets/SOURCES.md，并把参考图连同设计稿一起给用户看。查不到肖像的人物，如实告诉用户，改用剪影或只做时代通用造型，不要凭想象画出一张"像真人"的脸。然后为每人写出"形似"要抓住的特征（发型、脸型、体格、标志性服装或物件），并按所选画风画出角色设计稿，存到 `characters/`。设计稿按 `references/characters.md` 绘制，交给用户前放大到 100% 过一遍那里的自查清单（接缝、等粗四肢、几何体轮廓、关节）。如果用户要的精细度超出代码绘制的上限，把那份文件末尾的两种替代方案告诉用户，由用户选。次要人物用简化造型或剪影，不必单独设计。

## 6. 招牌镜头

从脚本里挑 1–3 个最值得重点做动画的时刻（高潮、转折、最有画面感的事件），简述动画构想。

## 输出

用户确认后，把以上内容写入 PROJECT.md 的"本期视觉设定"一节。之后所有分镜和画面都按这份设定执行；用户在制作中的修改也同步更新到这里。
