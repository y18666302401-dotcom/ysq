# 画风：逐帧手绘

> 默认主画风是在本画风之上叠加电影化 2.5D 处理，见 `hand-drawn-cinematic.md`。本文件只规定画法本身。

像传统 2D 手绘动画一样：每一张画都是"重新画"的，线条会轻微颤动，色块手工上色，特效也是画出来的。全部画面用代码绘制，**真实照片不出现在画面上**。

## 节奏：一拍二

- 每秒 12 张画，输出 24fps，每张画停两帧。实现方式：渲染时把时间量化为 `张数 = floor(t × 12)`，所有动画状态、镜头位置、震动都按量化后的时间计算。
- 物理计算（摆动、坠落、碰撞）仍按连续时间预先算好，只在取值时量化，保证运动轨迹自然。

**画法用 `scripts/examples/fine-hand/brush.js`**（用户确认的细腻画法，先看那里的 README 和对比图）。下面是它要达到的效果；不要退回"同一个形状每张随机抖一下 + 等粗墨线 + 平涂 + 满铺平行排线"的旧画法，那样画出来像矢量图加滤镜，不细腻。

## 线条：有笔压，每张重新画

- **笔压**：起笔轻、中段重、收笔尖；闭合形状背光一侧（主光左上 → 右下侧）明显更粗，受光一侧细。
- **每张画都重新画**：每张画换一组低频噪声，线条位置和粗细都有细微差别，但形状连贯（不是给控制点加随机抖动）。
- **修线痕迹**：长线条偶尔在旁边补一笔细的、淡的线。
- **主次分明**：外轮廓最粗（4–6px），结构线中等（2–3px），纹理和远景最细（1–2px）。远景线条可以用深蓝等有色线，拉开空间层次。受光的边缘（屋脊、背脊、岩脊）用一笔浅色线提亮。
- 墨色用暖黑 #1B1511，不用纯黑。直角物体（房子、木箱）用不平滑的折线，有机物体（人、动物、云、叶子）用平滑曲线。

## 上色：水彩式

- **边缘积色**：颜料在形状边缘积得更深（沿边几圈由深到浅）。
- **色面不匀**：每块颜色里有几块大的深浅变化，位置固定、不随帧跳。
- **颗粒**：叠一层颗粒纹理，跟着物体走。
- 色块和线条错位 1–3 像素，像手工上色。半透明的东西（气体、光束、雾）保持平涂半透明。
- **排线顺着形体，只排在背光的一侧**；更深的地方叠一层交叉排线；圆的东西（罐子、牛肚子、云）排线顺着曲面弯。整面背光的侧墙才整块排线。
- 天空用渐变底 + 一团团画出来的云（扇贝形的圆鼓轮廓、底部平、受光一侧描亮边），不要画成横贯画面的直条纹。
- 整个画面最后叠一层纸纹（multiply，强度适中，不能脏）。

## 细节：画到"经得起放大"

细腻主要来自结构细节，不是来自线条。每个主体物件至少画出这几层（以一间房子为例，其他物件同理：材质纹理、结构接缝、磨损痕迹、阴影）：

| 部位 | 要画的细节 |
|---|---|
| 墙 | 材质纹理（砖缝、木板、抹灰，断续的短线）、补丁、裂纹（带分叉）、墙脚的污渍 |
| 屋顶 | 瓦片 / 瓦楞 / 茅草的重复结构（暗线 + 旁边一道亮线）、钉子或绑绳、雨水冲出的锈迹或水渍、屋檐厚边、屋脊受光 |
| 门窗 | 木板、木纹、铰链、门框；窗里的灯光、打开的窗板 |
| 阴影 | 屋檐下的阴影带、侧墙整块排线、正面背光侧排线 |

动物、人物同样要有结构：躯干的起伏（肩、背、腹）、带关节的四肢、手脚或蹄爪、毛色斑纹等特征；不要画成"方盒子身体 + 四根棍子腿"。远景物件按距离缩小、减少细节，不要和近景一样大。

## 特效都要画出来

- 冲击：锯齿状的手绘爆点 + 放射状速度线，只持续 1–2 张画。
- 碎片：木屑、冰屑、纸屑都是带描边的小形状，按物理抛物线飞散。
- 快速运动：加 1–2 张拖影帧（运动方向上的几道弧线）。
- 天气：雪、雨画成短线段，分前后两层，速度和粗细不同。

## 人物

- 按 rules.md 的人物规则：外观自由设计，发型、脸型、体格、服装要有辨识度。
- 造型用简单的几何形打底，比例偏结实、有辨识度，不要画成瘦长的"默认脸"。
- 动态最少要有：呼吸（整体轻微缩放）、眨眼（每 2–3 秒闭眼 2 张画）。
- 有动作的人物用骨架 + 关键姿势表演，做法见 rules.md 的"人物"和 `scripts/examples/character-rig/`。
- 人物背景必须是故事世界里的环境，不放装饰性图形。

## 镜头与构图

- 镜头运动也按一拍二量化，避免"画是手绘的、镜头却像数码平滑推拉"的割裂感。
- 侧面或正面这类清晰易读的视角优先；先让观众认出"这是什么"，再展示细节。
- 竖屏时，主体完整入画，顶部和底部安全区不放关键内容。

## 照片的用法

真实照片只当绘画参考，用来确认船只、车辆或建筑的结构、服装和道具的样式，画面上不出现照片（何时查参考见 05-animation.md）。

## 禁止

- 平滑的数码渐变大面积铺色、发光特效、塑料质感（例外：大气景观镜头的天空渐变、真实光源的光晕和溢光，见 hand-drawn-cinematic.md 第 11 节）
- 等粗墨线 + 纯色平涂 + 满铺平行排线的旧画法
- 方盒子身体、棍子腿的动物，圆圈叠成的树，横条纹的云
- 所有线条完全静止（失去手绘感）
- 线条抖动过大，导致形状"游动"
- 没有故事含义的装饰图形
