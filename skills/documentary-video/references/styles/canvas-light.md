# 画风：Canvas 光影

像一部节奏舒缓的自然科普片：大面积渐变天空、层层叠叠的远山剪影、柔和的发光粒子和光束，画面沉静而通透。全部用 Canvas 2D 绘制，每一帧由 `render(t)` 按时间算出来。用户确认过效果的样片：`scripts/examples/sky-blue-15s/sky.html`（15 秒竖屏，"天空为什么是蓝的"）。

和另外两种画风的区别：扁平插画禁止渐变和发光，逐帧手绘靠颤动的墨线；本画风恰恰靠**渐变、发光和光的运动**出质感，运动平滑（30fps，不做一拍二），没有描边。

## 适合

自然现象、天文宇宙、物理化学、地理气候、"为什么"类科普，以及需要营造氛围（黎明、深夜、深海、太空）的历史片段。不适合大量人物表演和对话的故事——人物在本画风里多以剪影出现。

## 层次与空间

- 画面由远到近至少四层：**渐变天空 → 远山/云层 → 中景主体 → 近景剪影**。每层平移速度不同（远慢近快），形成视差。
- 山脊用几组正弦叠加的起伏线生成，越近越暗、越高；山脊上沿加一道 2–3px 的**轮廓光**（颜色取主光源色），山脚叠一层横向的**雾带**渐变。
- 云用一张离屏画布预先画好（几十个径向渐变圆叠加后整体模糊），之后只做平移，不每帧重画。
- 人物和建筑一律是纯色**剪影**，只在受光一侧加一道细轮廓光，不画五官。剪影的外形最容易暴露"几何体拼接"，人物和动物剪影按 `references/characters.md` 用 `scripts/character_kit.js` 绘制（`line: null`、`shade: false`、`rim` 设为主光源色）。

## 光

- **光源是每个画面的主角**：太阳、灯、发光体都用"实心核心 + 两层径向渐变光晕"表现，光晕用 `globalCompositeOperation = 'lighter'`（叠加发光）。
- 光束、光线用细长渐变多边形或带渐隐尾巴的线段；粒子运动时拖一段渐隐的尾迹。
- 环境里一直有缓慢漂浮的光点（尘埃、星光、散景光斑），靠近光源的更亮。
- 光晕、散景、粒子图案都预先渲染成离屏画布（sprite），每帧只 `drawImage`，保证速度。

## 配色

- 每个场景一套**冷暖对比**：冷色的天和暗部（深蓝、靛紫），暖色的光源和高光（琥珀、桃粉）。
- 场景之间的色彩变化用插值慢慢过渡（例：夜 → 黎明 → 白天），本期的色彩脚本在 PROJECT.md 的"本期视觉设定"里定。
- 黑位压低、颜色要浓的要求照 rules.md 执行；白天的亮场景可以整体偏亮，但四周必须有暗角压住。

## 质感叠加（每一帧最后做）

1. **暗角**：径向渐变，中心透明、四周约 50% 黑。
2. **胶片颗粒**：一张 256×256 的噪点图，`overlay` 模式、约 7% 不透明度，每帧按帧号偏移位置（确定性），让颗粒"活"起来。
3. **首尾淡入淡出**：片头约 0.6 秒、片尾约 0.5 秒从黑场进出。

## 文字

- **标题**：衬线粗体（如 Noto Serif SC 700），逐字从下方升起并淡入（每字错开约 0.08 秒），下方一道细线由中间向两边展开，再出一行字距拉开的副标题。文字带柔和的深色投影。
- **字幕**：无衬线中等字重（如 Noto Sans SC 500），放在半透明深色**圆角胶囊底衬**上，淡入时轻轻上移。重点词标色仍按 rules.md 的"字幕"一节。
- **标注**：细线引出 + 两行文字（名称大、说明小），跟着被标注的物体出现和消失。
- **信息卡**：半透明深色圆角卡片，细边框，里面可以放动态示意（如两种波长的波形实时滚动）。
- 公式、关键结论用大号衬线字单独成画面。

## 镜头与转场

- 镜头只做缓慢的推拉和平移，用缓入缓出曲线，任意时刻都在轻微运动。
- **转场 = 推进 + 交叠**：上一个场景镜头加速推进（放大约 1.5–2 倍）的同时，下一个场景从略微放大的状态退回正常，两者交叠约 1 秒。这是本画风允许的唯一一种交叠转场，不用硬切、划像、圆形遮罩。
- 转场要有动机：推进的目标是下一场景的主题所在（例：推进太阳 → 进入光束的微观世界）。

## 动效

- 主运动是**光的运动**：光束射入、粒子飞行、散射、汇聚到眼睛。物理过程用简单的运动学（匀速直线、碰撞后换方向、按寿命渐隐）预先算好起止时刻，按时间取值。
- 次级运动：被击中的分子荡开一圈光环、粒子微微抖动、星光闪烁、云层飘移、山层视差。
- 环境运动：尘埃漂浮、散景光斑缓慢游移、颗粒闪动。
- 跟词走的动作（光束射入、标签出现、公式出现）时间点取自 `audio/words.json`。

## 实现要点（直接照样片改，不要从零写）

- 一个 HTML 文件，一个 1080×1920（或 1920×1080）的 `<canvas>`；全局只有 `render(t)` 一个入口，按时间段决定画哪几个场景、每个场景的透明度。
- 页面导出 `window.VIDEO = {W, H, FPS, DUR}` 和 `window.renderFrame = n => render(n / FPS)`，就能用 `scripts/render_canvas_page.js` 无头渲染成 MP4，或者抽帧做联系表自查。页面本身同时是可以拖动时间轴的预览播放器。
- 随机数一律用固定种子的 `mulberry32(seed)`，在页面加载时生成好所有星星、粒子、云的位置；`render` 里不调用随机数。
- 缓动函数：`ss`（smoothstep，用于淡入淡出窗口）、`eio`（三次缓入缓出，用于镜头）、`eout`（四次缓出，用于文字入场）。
- 有 HyperFrames 的环境：把 `render(t)` 接到 `hf-seek` 事件即可；没有 HyperFrames（例如 claude.ai 网页对话）直接用 `render_canvas_page.js`。
- 长片按场景拆成多个 `sceneX(t, alpha)` 函数，每个场景只在自己的时间窗内被调用；长视频分段渲染（`--from/--to`），最后用 ffmpeg 拼接。

## 禁止

- 描边线条、卡通式的五官和表情
- 纯平涂没有任何渐变或光的画面（会显得"淡"，失去本画风的质感）
- 发光过度导致大面积白色过曝、文字看不清
- 没有故事含义的光斑和装饰（散景光点属于环境，不能抢主体）
- 硬切、划像、圆形遮罩转场
- 用 `Math.random`、`Date.now` 驱动画面
