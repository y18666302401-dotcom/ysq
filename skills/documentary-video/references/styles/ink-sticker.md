# 画风：墨线贴纸（可选）

一句话：米白纸上，深墨线条把世界"画出来"，平涂的柔和色块像贴纸一样带偏移投影，角色和物件靠挤压拉伸蹦出来、做表演。灾难发生时，同一套语言把画面吞没。

用户确认过的样片：`scripts/examples/ink-sticker/`（`pompeii.js` 火山喷发全景、`street.js` 面包房门口的动物；**人物一律用 v2：`char34.js`，完整用法看 `bucket-60fps/`**）。做之前先读这些文件和本文件。

**帧率：60fps 输出**（用户 2026-10-11 选定）。人物动作、镜头、烟云逐帧平滑；**墨线抖动仍然每秒 12 次**（`G.K = floor(t*12)`），所以 60fps 只让动作更顺，线条不会抖得更快。帧率只影响本机渲染时间（约 30fps 的 2 倍），不影响写代码的工作量。

## 1. 材质与配色

| 元素 | 规则 |
|---|---|
| 纸 | 米白 `#EFE6D6`，淡淡的纸纹（几百个低透明度色斑 + 细颗粒）；最后再用 multiply 叠 10% 纸纹，让色块也带纸感。纸纹不能脏：色斑透明度不超过 0.04 |
| 墨线 | 深蓝墨 `#232845`，线宽 5–6 px，圆头圆角；每秒重画 12 次，每次用低频噪声让线条位置偏 1–1.5 px（"抖线"），形状连贯不乱抖 |
| 色块 | 平涂、柔和、偏粉：鼠尾草绿、草绿、雾蓝、赭黄、庞贝红、陶土橙、米白墙。色块与墨线错位 1–2 px（用另一组噪声种子），像手工上色 |
| 贴纸投影 | 物件下方偏移 (8, 10) 的半透明暖褐色同形状 `rgba(70,50,30,0.16)` |
| 强调色 | **红色只给最关键的东西**（岩浆、孩子的球）：全片只有它是饱和红，观众的眼睛会一直跟着它 |
| 灾难色 | 灰烬、烟云用暖灰 `#BDB3A8`/`#8E847B`；天色变暗用 multiply 叠暖灰，逐步加到约 0.5 |

## 2. 画面语言

- **线条先画、色块后铺**：开场 0–2 秒，地平线、山、海岸线按路径一段段画出来，能看到笔尖（一个墨点）；色块随后从一侧或从下往上，用波浪形的边"铺"开。
- **物件蹦出来**：房子、树、云、角色出场用 `backOut` 的挤压拉伸（先压扁、再拉长、回到原形），彼此错开 0.05–0.15 秒，像在一页页往上贴。
- **菜花状的云 / 烟 / 碎屑流**：一组圆，先画加粗一圈的墨色圆，再把所有圆填上颜色，只剩外轮廓一圈墨线；每个圆左上角叠一个浅色圆做受光。烟柱靠圆的出生时间和目标位置长出来，伞状顶部、崩塌后的碎屑流都用这个方法。
- **冲击短线**：撞击、爆发、落地的瞬间，周围放射出 5–9 根短墨线，向外弹开后消失（代替光效和粒子）。
- **地震**：整幅画面抖动，物件绕底部小幅摇晃，音乐跟着跑调。
- **结尾"新的一页"**：灾难吞没画面后，叠一层灰白（约 0.86）只留淡淡的轮廓，再逐字写出标题；文字可以用墨色字 + 米白描边，压在任何底色上都清楚。

## 3. 人物与动物

### 人物 v2（`char34.js`，用户 2026-10-11 确认，替代 street.js 的 `drawHuman`）

旧版的问题：每个部件单独描一圈边，肩、肘、胯、脖子处全是接缝；四肢是粗细均匀的"面条"，拼接感强；人物纯侧身。v2 的做法：

- **3/4 侧身**：两个肩膀都看得到（远肩窄、在躯干后），手臂和腿分别从左右两侧长出来；躯干有前胸和侧面两个面（侧面落在暗部），前襟线偏向朝向的一侧，腰带中间往下弯（圆柱透视）；脸上近眼正常、远眼横向压到约 0.66，鼻子略伸出脸的轮廓，耳朵在后侧；鞋按透视缩短。朝左用 `dir = -1` 整体镜像。
- **整体外轮廓，不逐部件描边**（`renderFigure`）：① 所有部件加粗描边 + 填墨，得到整个剪影的一圈外轮廓（再错位 1.6/2.2 px 叠一次，右下方的线更粗，线条有轻重）；② 按前后顺序铺色，色块互相盖住，内部接缝消失；③ **只在真正有前后遮挡的地方补内线**（近臂压在躯干上、近腿压在远腿上、鼻子、耳朵、发际线、帽檐、腰带）：内线比外轮廓细（约 3.6 px），两头收尖，从关节那一头由 0 长出来，所以关节处不会出现一圈圆。部件用 `over: [被它挡住的部件名]` 声明。
- **锥形连续四肢**（`limbPoly`）：一条胳膊 / 腿是沿骨骼中心线（肩→肘→腕，经平滑）的一整条多边形，宽度按 根部 → 肌肉 → 关节收窄 → 小腿肚 / 前臂 → 腕踝最细 变化；袖口是一条收尖的横线，不是断开。
- **一档阴影**：每个部件把自身形状往受光方向平移、与自身相交得到亮面，其余是暗一档的颜色，有体积感；远侧手臂、腿整体用暗一档的颜色。
- 造型 = 一组参数（腿长、躯干、头、衣服三档色、裤袜色、发色、帽子 `kettle / coif / cap`、胡子、绗缝、胸前纹章，按题材扩展），同一人物全片同一组参数。手里的道具作为部件插在近手臂之前（`insertBefore(fig, 'armN', parts)`），圆手掌自然盖在道具上（手一律是哆啦A梦式的圆手掌，不画手指和拇指；耳朵是 C 形，见 rules.md 第 6 节）。
- **内线和颜色交替画**：每个部件铺完色立刻画它自己的遮挡内线，后面的部件铺色时会把它盖住——后面部件（耳朵、发际线）的线不会透过前面的帽子、头巾。
- 特写镜头放大人物时，用 `renderFigure` 的 `box` 参数把离屏画布加大，否则头会被裁掉。
- 人物的贴纸投影是整个剪影一次性投出来的，不是逐部件。

### 五官与表情（v3，用户 2026-10-11 确认，所有人物通用）

旧版的问题：眼睛是粗圆圈、两只眼几乎贴在一起，看起来像戴了圆眼镜；闭眼只是盖一层肤色、圆圈还在；鼻子是贴上去的小疙瘩；嘴是悬空的椭圆；戴帽子时发际线横穿额头；络腮胡是一整块、嘴画在胡子上。现在的画法（`char34.js` 的 `eyeV2` 和 `buildMan` 里的 details）：

- **眼睛**：杏仁形眼白 + 细轮廓（约 2 px）；上眼皮是一道粗的收尖线，外眼角略上挑；大虹膜 + 瞳孔 + 一大一小两个高光，看向 `look`。两眼拉开：近眼在脸的中线附近，远眼在鼻梁另一侧、横向压到约 0.68。**闭眼是一道下弯的弧线**，不画眼白。
- **眉毛**：粗、两头收尖，是表情的主力。高低随 `brow`，眉头角度随 `browAng`（+ 皱眉 / 生气，- 发愁）。
- **鼻子**：在眼睛下方、两眼之间偏远侧，鼻尖略伸出远侧脸颊的轮廓（参与整体剪影）；内线只画鼻底和鼻孔。
- **嘴**：按 3/4 透视，近侧半边长、远侧半边短。闭嘴是一条收尖弧线，`smile` 控制嘴角上扬 / 下撇，笑时近侧嘴角有小酒窝；张嘴（`mouth`）是深色口腔 + 舌头，张大时露上牙。
- **胡子**：络腮胡的上沿在嘴下面；八字胡单独一个形状盖在嘴的上沿。
- **头发**：戴帽子时只留帽檐下的鬓角和后脑一撮，不画横穿额头的发际线；帽檐要高过眉毛，眉毛必须露出来。
- **表情参数**：`look`、`lid`（上眼皮 0 瞪大…1 闭）、`squint`（下眼皮上推：笑、怒）、`brow`、`browAng`、`smile`、`mouth`、`blink`。不给时按 `brow` / `smile` 推一个默认值。常用组合：

  | 表情 | 参数 |
  |---|---|
  | 平静 | 默认 |
  | 得意 | `smile: 0.9, brow: 0.6, lid: 0.35` |
  | 吃惊 | `mouth: 0.8, brow: 1.8`（自动瞪大） |
  | 生气 | `mouth: 0.5, smile: -0.5, brow: -1.4` |
  | 发愁 | `smile: -0.6, brow: 0.6, browAng: -0.8, lid: 0.3` |
  | 鬼祟 | `look` 斜瞟、`smile: 0.5, brow: -0.6, lid: 0.45` |
  | 睡着 | `blink: 1, mouth: 0.25` |

- 新人物造型做完，先跑 `face_sheet.js` 出一张表情表（每个人物 × 7 种表情的头部特写）自查，再进动画。

### 动物、步态、表演（沿用 street.js）

- **狗**（`drawDog`）、**驴 / 马类**（`drawDonkey`）、**鸽子、猫** 见 street.js。新做动物时同样按 v2 的方式：部件合成整体剪影描一圈外轮廓、只在遮挡处补收尖内线、腿用锥形连续多边形。
- **步态不滑步**：`gait()` 让支撑期的脚钉在落脚点（世界坐标不动），摆动期抬脚划弧迈到下一个落脚点；人两只脚相位差 0.5。起跑用"先加速再匀速"的位置曲线。脚的世界坐标转人物局部坐标见 `bucket-60fps/sample.js` 的 `toLocal`。
- **关键姿势**：每个大动作先蓄力再过冲——受惊（往下一沉压扁 → 跳起拉长 → 落地压扁回弹）、转身逃跑（横向压扁 0.75 → 回弹）、得意举起（backOut 过冲）。
- **手里的东西会晃**：提着的东西按手的世界坐标做阻尼摆（预先积分），跑动、急停时自然甩动。
- 角色出场也用挤压弹出。地面上每个角色带一个软椭圆影子，跳起时影子缩小。

## 4. 夜景（用户 2026-10-11 确认，所有夜景通用）

旧做法是给整幅画叠一层灰紫 multiply：颜色发闷、对比度低，灯光只是一团雾。现在的做法（工具 `night.js`，完整示例 `night_example.js`）：

- **夜色调色板，不整体压灰**：每种白天的颜色用 `N(col, k)` 换成它自己的夜色——偏冷、偏暗，但原来的色相差和明暗差保留，墙、屋顶、衣服在夜里还分得清。`k` 是此处受到的暖光强度（`falloff` 按到光源的距离算），越靠近灯火越偏暖。
- **暖光源是画面的主角**：灯笼、火把、篝火、亮着的窗是全画面最亮、最暖的点（火苗 `flame`、亮窗 `litWindow`、光源光晕 `halo`）。光照到地上、墙上用 **2–3 圈阶梯式平涂光池**（`pool`，普通叠加的暖色，不用 screen、不用模糊渐变——否则发灰、失去贴纸感）。每个夜景至少一个看得见的暖光源。
- **人物受光**：`renderFigure(..., nightOpts({ x, gy, dir, light, k, moon }))`——朝光源一侧是暖色受光面、另一侧是冷暗面（`litDir` 按光源方向算），细节颜色（扣子、绗缝、眼皮）也跟着换色；发光的部件（灯笼玻璃）标 `glow: true` 不换色。
- **月光轮廓**：人物朝月亮的一侧边缘一道约 3 px 的冷蓝色轮廓光（`moonRim`），把人从暗背景里分出来；方向按月亮位置换算到人物局部坐标，朝左的人物要镜像。
- **天空**：四条波浪边的平涂深蓝色带 + 会闪的四角星（`nightSky`）；月亮是奶油色圆 + 一档阴影 + 环形山 + 两圈平涂月晕（`moonDisc`）。
- **墨线**换成更深的夜墨色 `NIGHT_INK`，贴纸投影和脚下影子用更深的冷色（`FIG_SHADOW`、`GROUND_SHADOW`）。
- **纸纹**：最后用 `paperOverlay` 以 overlay 叠一层中性灰颗粒，暗部也看得到纸。
- 不要：整体叠灰 / 叠紫压暗；没有任何可见光源的夜景；模糊的大光晕代替光池；月光轮廓粗到像描了一圈白边。

## 5. 构图（竖屏 9:16）

- 人物镜头用镜头放大（约 1.3 倍）把街道层推到画面中下部，人物不要缩在一条细带里；上方留给远山和烟柱。
- 底部约 450 px、顶部约 200 px 是平台界面区，角色的脚和结尾文字不要落进去。
- 结尾推镜头到一个有故事含义的小物件上（掉在地上的面包、孩子留下的球），再写文字。

## 6. 动效节奏与声音

- 开场 2 秒内把世界画完，最晚 3 秒进入事件征兆。
- 日常段落的声音偏可爱（拨弦、钢片琴的"叮"、啵、铅笔沙沙），和后面的灾难形成反差；事件前一刻全部骤停。详见 audio.md。

## 7. 自查

- 抽 8 张关键帧排成联系表，看：线条是否在画、色块是否铺开、贴纸投影有没有、红色是否只用在关键物上。
- 人物动作抽连续帧（每 0.15 秒一张，排成两行）看滑步、穿模、僵硬。
- 人物放大看关节：肩、肘、胯、脖子处不能有一圈圆形接缝；内线只出现在遮挡处，两头收尖。
- 五官：两眼分开、不像眼镜；闭眼是弧线；眉毛露在帽檐下；嘴不画在胡子上。新人物先出 `face_sheet.js` 表情表。
- 夜景：看得见暖光源、光池是阶梯平涂、人物有朝光暖面和朝月冷轮廓；画面不能发灰发闷。
- 不要出现：渐变发光的写实特效（爆炸用冲击短线和菜花云表现）、没有墨线的物件、过脏的纸纹。
