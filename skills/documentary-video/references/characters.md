# 角色造型：画成一个整体，不要拼几何体

用代码画人物和动物，最容易出的问题是"一看就是拼起来的"：头是正圆，身体是椭圆，四肢是等粗的胶囊，每一块各描一圈边，关节处全是接缝。观众不一定说得出哪里不对，但会觉得粗糙、像占位图。

前后对比样片：`scripts/examples/character-quality/compare.html`（左旧右新，同一只猫、同一个人物），截图 `compare.jpg`。工具库：`scripts/character_kit.js`。

## 拼装感从哪里来，怎么改

| 拼装感的来源 | 改法 | character_kit 里的工具 |
|---|---|---|
| 每个部件各描一圈边，脖子、肩膀、大腿根都有接缝 | 同一层的部件**只描一次合并后的外轮廓**；近侧的腿、手臂和身体相接处，边线在身体里**淡出** | `figure()` 的图层（`layers`）和 `joins` |
| 四肢、脖子、尾巴是等粗的管子 | 沿一条骨线按**粗细曲线**生成轮廓：大腿根粗、膝盖收、小腿鼓、脚踝细、爪子再放大 | `tube(骨线, 粗细曲线)` |
| 头是正圆、身体是椭圆、耳朵是三角形贴上去的 | 用 8–20 个控制点画一条**平滑闭合曲线**，耳朵、腮毛、鼻子、胡子都并进同一条轮廓 | `blob(控制点)` |
| 急弯的肘、膝内侧折出尖角或自相交 | 急弯处拆成两段、各带圆头，放在同一层，合并轮廓后关节自然圆顺 | 两个 `tube` + 同一层 |
| 线宽处处一样 | 背光一侧的外轮廓更粗；内部的线（眼皮、皱褶、条纹、胡须）**两头收尖** | `figure()` 的 `weight`、`ink()` |
| 阴影是另外贴上去的椭圆色块 | 暗部 = 形状沿光的方向平移后没被覆盖的那一条**月牙**，自动贴着轮廓走；花纹一起变暗 | `figure()` 的 `shade` / `shadeDepth` |
| 身体是一块平的色，没有体块 | 在体块转折处加一两条内部结构线（大腿肌肉、肩胛、肘窝、衣服的褶） | `ink()`，画在图层的 `after` 里 |
| 五官是圆点和圆圈 | 眼睛是杏仁形（两头尖），有上眼皮线、瞳孔、高光；猫的瞳孔是竖条；嘴、鼻子用收尖的线 | `blob` + `ink` |

## 画一个角色的步骤

1. **先看参考**：动物找几张同一角度的照片，人物按 rules.md 先查肖像资料。看清体块比例（猫：胸深、腰细、臀部是一大块肌肉；老人：肩膀下垂、背微驼）。
2. **定姿态线**：一条从头到尾（或从头到脚）的弧线，决定角色是挺拔、松弛还是紧张。直挺挺的竖线和横线最显假。
3. **画大轮廓**：躯干、头各用一个 `blob`。控制点沿着参考照片的外形点，而不是画一个椭圆再修。尖角（耳尖、发梢、衣角）用两个靠得很近的控制点。
4. **分图层**：按前后顺序分层，每层内部只有一条合并轮廓：
   - 远侧的腿、手臂（颜色深一档）
   - 躯干 + 尾巴（尾巴根插进躯干里，同一层就没有接缝）。同一层里**插进去的部件先填色**（`parts` 里排前面），主体后填色盖住接口，否则插进去那一截的端头和暗部会压在主体上，露出一个小台阶
   - 近侧的腿、手臂（`joins` 指向躯干，边线在关节处淡出）
   - 头（后脑和脖子相接处用 `joins` 淡出；下巴压在胸口上保留边线）
5. **四肢用 `tube`**：骨线经过每个关节；粗细曲线至少 4 个点，写出肌肉的鼓起和关节的收窄。两段关节用 `ik2` 求关节点，急弯时拆成两段。
6. **加细节**：花纹、肚皮、衣领放在部件的 `detail` 里（自动裁剪在部件内，之后统一叠暗部）；跨部件的线和五官放在图层的 `after` 里。
7. **放大到 100% 自查**（见下面的清单），再给用户看设计稿。

```js
// 一条前腿：骨线经过肩、肘、腕、爪；粗细从 30 收到 12，爪子处放大到 13
const leg = CharKit.tube([[100,-150],[95,-86],[103,-26],[106,-14]], [[0,30],[.3,22],[.6,14],[.88,12],[1,13]]);
CharKit.figure(ctx, [
  { parts: [{ pts: torso, fill: '#F39A3B', shade: '#D9A890', detail: drawStripes }] },
  { parts: [{ pts: leg, fill: '#F39A3B', shade: '#D9A890' }],
    joins: [{ at: [100,-150], r: 62, into: torso }] },   // 腿从身体里长出来
], { line: '#2A1F33', lw: 6 });
```

## 动起来以后仍然是一个整体

- 动画只改骨线和控制点（呼吸改肚皮的点，摆尾改尾巴骨线，抬手改 `ik2` 的目标点），每帧重新生成轮廓，再交给 `figure()`。不要把部件整块旋转、平移来做动作，那样关节处会露馅。
- 呼吸：胸口、肚皮的点上下动 2–3px，背线几乎不动。
- 尾巴、头发、衣角：骨线上的点用相位依次延后的正弦摆动，越靠末端越晚、幅度越大。
- 角色旋转或翻转后，光仍从画面同一侧来：`figure()` 会把 `light` 换算到角色自己的坐标里。

## 三种画风怎么用

| 画风 | figure() 的设置 | 说明 |
|---|---|---|
| 逐帧手绘 | `line: '#1B1511'`，`weight` 约线宽的 0.6 倍，`shadeMode: 'multiply'` | 轮廓点先过 `jitter(点列, 1.5–2.5, 张数)` 再画，线条按张颤动；暗部也可以换成排线（在 `detail` 里画） |
| 扁平插画 | `line: null`，`shadeMode: 'source-over'`，`shade` 用同色系深一档的平涂色 | 没有描边，合并轮廓靠同一层同色；月牙形暗部就是"双色分面"的暗面，也可以在 `detail` 里手动切一刀分面 |
| Canvas 光影 | `line: null`，`shade: false`，`rim: 主光源色`，`rimDepth: 2–4` | 人物是剪影，只在受光一侧留一道轮廓光；剪影的外形同样要用 `blob` / `tube`，剪影最怕"一眼看出是几何体" |

在 Node 里用（扁平插画的 `@napi-rs/canvas` 管线）：先 `CharKit.useCanvas((w, h) => createCanvas(w, h))`，告诉工具库怎么建离屏画布。

## 自查清单（角色设计稿和每个招牌镜头都要过一遍，放大到 100% 看）

- [ ] 身体内部没有不该有的接缝线（脖子、肩膀、大腿根、尾巴根）
- [ ] 没有等粗的四肢、尾巴、脖子；每条都能指出哪里粗、哪里细
- [ ] 头、身体不是正圆或椭圆；遮住五官只看剪影，也认得出是什么、在做什么
- [ ] 关节弯曲处圆顺，没有尖角、缺口或自相交
- [ ] 内部的线两头收尖，外轮廓有粗细变化
- [ ] 暗部贴着形状走，和全片光的方向一致
- [ ] 关节淡出处没有残留的灰影或断头线
- [ ] 动作时（抽 3 帧看）关节处不露馅，部件之间没有错位的缝

## 还可以走的另外两条路（由用户决定）

代码绘制再怎么改，精细程度也有上限。需要更细腻的特写（人物正脸、复杂服饰）时，可以把这两种方案告诉用户：

1. **SVG 手绘稿 + 分件绑定**：先把角色画成一份精细的 SVG（大量贝塞尔锚点，可以由 Claude 照参考图逐段写出，也可以由用户或画师在 Figma、Illustrator 里画），按头、躯干、上臂、前臂、手……拆成部件，关节处部件互相压住，再用代码按骨骼驱动（类似 Spine、Live2D 的切片动画）。精细度最高，但动作幅度受限，每个角色的准备时间长。
2. **AI 生成的角色立绘**：只有用户明确同意时才用（见 05-assets.md 的降级顺序），不生成写实的真实人物肖像；生成后同样拆件绑定，并在 SOURCES.md 登记。

两种方案都要先出设计稿给用户确认，再全片复用。
