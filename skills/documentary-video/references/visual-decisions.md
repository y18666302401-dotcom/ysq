# 本期视觉设定（Claude 自主决定，不问用户）

拆分镜之前，根据这一期的故事和所选画风，由你自己定下本期画什么、各代表什么。**不给用户列选项、不等用户确认**；用户看到的是分镜表和招牌镜头，觉得不对时会直接提。

画风文件只规定"怎么画"，这里决定"这一期画什么"。所有决定都从故事出发：先问"这个故事里观众需要看懂什么、感受到什么"，再选能表达它的东西。没有故事理由的元素一律不加。

## 要定的东西

按故事需要选用，用不上的就不要：

- **布景清单**（必定，扁平插画除外）：80–90 秒的片子定 3–5 个布景，每个写清：地点、时间（白天 / 黄昏 / 夜里）、主光源（太阳、月光、窗灯、火光……夜景必须有看得见的光源，见 styles/hand-drawn-cinematic.md 的"夜景用光"）、四层各放什么、哪些示意信息画在这个布景里。宁可少几个地点，把每个画满（密度要求见 hand-drawn-cinematic.md 的"布景密度下限"）。
- **贯穿全片的视觉符号**：故事里本来就有的关键物件、场所或线索（例：一只比萨盒、一面调查墙、一条航线），反复出现、串起全片。优先从故事本身取，不另造吉祥物或虚构角色。
- **线条与标记的含义**：故事需要在地图或关系图上表达路线、联系时才用。最多三类（如：实际发生的 / 原本计划或推测的 / 意外或被动的），用颜色或线型区分，全片统一，第一次出现时让观众看懂。道具贴合时代和场景（航海用航海图和分规，案件用调查墙和红线，商业用白板）。
- **时间计数器**：故事跨度大、时间感重要时才用，选最贴合的形式（日历、"出发第 X 天"、"失踪第 X 小时"、人物年龄等）。
- **配色与信息标色**：主基调和随剧情变化的色彩走向（例：启程温暖 → 困境转冷 → 低谷最暗 → 结尾一丝暖光）；时间、地点、数字、普通文字四类标色（默认值见 rules.md 的"字幕"，扁平插画从本期配色里选）。
- **人物造型**：自由设计，不查肖像、不追求像真人。事件是真实的，人物外观可以是虚构的：按故事里的身份、时代、性格和报道中提到的特征（如"身材高大"），用所选画风设计一个有辨识度的形象。次要人物用简化造型或剪影。
- **色彩剧本与大气镜头**（默认画风必定）：全片的冷暖走向（如 夜 `night` → 灾难 `storm` → 余波 `dawn`），以及 2–4 个大气景观镜头放在哪（开场、灾前平静、余波、结尾），每个写清色板、唯一的暖色发光点是什么。规则见 styles/hand-drawn-cinematic.md 第 11 节。
- **配乐设定**（每期必写）：故事的时代与地区决定调式、主奏乐器、打击乐、卡通音效用什么本地乐器、本期禁用哪些乐器。按 audio.md 的"配乐要听得出时代和地区"一节查表填写，写在色彩剧本旁边，每个段落用什么声部也一并写下。
- **招牌镜头**：从脚本里挑 1–3 个最值得重点做动画的时刻（高潮、转折、最有画面感的事件），在分镜表的"画面类型"里标出来。
