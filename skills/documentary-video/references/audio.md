# 音效与背景音乐

声音分四轨：**旁白、背景音乐（BGM）、环境声、动作音效**。旁白见 04-voice.md；本文件管其余三轨和最后的混音。通用要求（四轨都要有、高潮可用突然安静）见 rules.md 的"声音"一节。

## 用哪种技术：分轨选择

| 轨道 | 默认方案 | 可选 | 为什么 |
|---|---|---|---|
| 动作音效（撞击、落地、脚步、嗖、啵、狗叫） | **程序合成**（numpy/scipy），时间点读动画导出的事件表 | 用代码编曲时直接用乐器演奏（木琴、定音鼓、镲） | 免费、零版权风险、和动画共用一组时间点，帧级对齐 |
| 环境声（风、海浪、雨、人群、机器） | 程序合成能做像的（风、远雷、灰烬沙沙、火的噼啪）就合成；做不像的用 **CC0 素材库** | ElevenLabs 文本生成音效（付费，算 AI 素材，先问用户） | 写实的人群、机器声程序合成做不像 |
| 背景音乐 | **代码编曲**（写谱 → 真乐器采样 + 合成器 → 混音，`scripts/music/`） | 环境没装好时用程序合成垫音；用户要求时用 Lyria 3 / 免版税曲库 | 节奏、和弦、每个声部、强弱都能卡到画面和旁白的具体时刻；免费、可商用 |
| 混音 | **`scripts/mix_audio.py`**：侧链闪避 + 两遍响度标准化 | — | 自动跟着旁白压低音乐，重录配音后不用重调；统一到平台推荐响度 |

背景音乐的默认值不用问用户。AI 生成音乐（Lyria 等）和 AI 生成音效属于 AI 素材，只有用户明确同意才用。

## 动作音效：程序合成

### 时间点从动画来，不手填

动画阶段每做完一个分镜，把这个分镜的事件追加到 `audio/sfx_events.json`（时间、类型、强度、声像），合成脚本照它放音效：

```json
[{"t": 2.90, "type": "thud", "gain": -16, "pan": 0.3}, {"t": 4.12, "type": "bark", "gain": -12, "pan": 0.55}]
```

能从代码里直接算出来的时刻都由动画导出，不要靠肉眼估：
- **物理模拟**的碰撞时刻（弹跳、落地、碎块撞地）：预积分时记下每次触地的时间。
- **步态**的落脚时刻（人、狗、驴的每一步）：`gait()` 里支撑期开始的时刻就是一步，人、狗爪、蹄子各用一种声音。
- **大量同类事件**（成千棵树倒下）：每个事件记时间、屏幕 x（换算成声像）、离镜头远近（换算成音量），合成时近的响、远的轻，取最近的上千个即可。
- **词时刻**：`audio/<语言>/words.json` 里关键词的开始时间。

### 合成配方（示例见 `examples/ink-sticker/*sound.py`、`examples/molasses-15s/sound.py`、`examples/carrington-10s/sound.py`）

| 声音 | 做法 |
|---|---|
| 爆炸 / 轰 | 正弦从 60–70 Hz 往 25 Hz 扫 + 低通噪声长衰减 + 中频噪声短衰减 + 高频脆响，`tanh` 软饱和；左右声道错开 30 ms 显得宽 |
| 落地 / 咚 | 低频正弦带快速下滑的音高 + 短促低通噪声 |
| 弹跳（卡通） | 正弦加快速颤动的音高，"啵嘤" |
| 啵（东西弹出） | 正弦从 300 Hz 快速扫到 1200 Hz，几十毫秒 |
| 拨弦 / 拨奏音乐 | Karplus-Strong |
| 钟、铃、钢片琴 | FM 合成（调制比 1.41）或正弦 + 4 倍频泛音 |
| 狗叫 | 锯齿波加快速下滑的音高 → 两个带通（共振峰）+ 一点噪声 |
| 驴叫 | 锯齿波在高音、低音之间交替 4 段（"嘻—昂"），带通 |
| 扑翅 | 带通噪声乘以 14–16 Hz 的方波门 |
| 呼啸（火球、风墙） | 带通噪声，中心频率和音量随接近升高，声像跟着画面位置移动 |
| 铅笔 / 写字 | 2.5–7 kHz 带通噪声乘以不规则起伏 |
| 树木折断 | 高通噪声短促衰减 + 随机音高的短正弦 + 近处叠一个低频闷响 |
| 耳鸣（爆炸那一刻） | 6 kHz 正弦慢衰减；同时把其他声音都抽空，等冲击波到了再轰 |

**声像**：用画面里的 x 位置换算（-1 左到 1 右），等功率声像（cos/sin）。火山在画面右边，爆炸就偏右。

## 环境声

先看能不能合成（风、海浪的低频起伏、雨、灰烬、火的噼啪都能）。做不像的才找 CC0 素材，下载前确认许可，来源记进 NOTES.md 的"素材来源"：
1. **Freesound.org**：许可筛选为 **Creative Commons 0**（CC BY 能用但要署名；CC BY-NC **不能**用于有收益的频道）。
2. **Sonniss GDC 免费音效包**：免版税、可商用、不需署名。
3. **Pixabay 音效**：可商用、不需署名。
- **不要用 BBC Sound Effects**：许可只允许个人、教育和研究用途。
- 环境声铺满整个场景，首尾各做 0.5–1 秒淡入淡出；场景切换时两段交叉过渡。

## 背景音乐：代码编曲（`scripts/music/`）

完整示例：`scripts/examples/cat-cartoon-15s/`（15 秒卡通样片，配乐和音效都用这套方法做，总谱是 `scripts/music/score_cat_example.py`）。

**四步流水线**

| 步骤 | 工具 | 做什么 |
|---|---|---|
| 1 写谱 | `score_*.py`（mido） | 把编曲写成音符事件，一个声部一个 MIDI 文件；合成器声部直接给出以秒为单位的音符 |
| 2 采样乐器发声 | `render.py` → `sfizz_render` | 每个声部一个 SFZ 乐器；SFZ 是纯文本，起音、释音、力度区、轮换都能直接改 |
| 3 合成器发声 | `render.py` → pedalboard + Surge XT | 装入 Surge XT 的出厂音色（3000 多个 .fxp），做铺底和琶音 |
| 4 混音 | `mix.py`（pedalboard） | 每轨按"有声部分"对齐到目标电平 → 各自的效果链 → 总线压缩限幅 → 两遍响度标准化 |

```bash
bash scripts/music/setup.sh ~/music-kit                       # 第一次：装 Surge XT、编译 sfizz、下采样库（约 3 GB），生成 sfzmap.json
python scripts/music/score_cat_example.py out                  # 写谱（新的一期照这个文件写自己的总谱）
python scripts/music/render.py out ~/music-kit/sfzmap.json     # 渲染分轨 out/stems/*.wav
python scripts/music/mix.py out --duration 15                   # 混音 → out/music_final.wav（-16 LUFS）
```

**Windows**：用 `scripts/music/setup_windows.py [目录]`（默认 `E:\music-kit`，本机已装好），不装系统软件、不需要管理员权限：
- sfizz 1.2.3 官方 Windows 包里自带 `sfizz_render.exe`，只取它和 `sfizz.dll`。
- Surge XT 用便携版（解压即用，`SurgeXTData` 在插件的上级目录里，插件自己找得到）。**pedalboard 要指向 .vst3 包里面的 DLL**（`Surge XT.vst3\Contents_64-win\Surge XT.vst3`），直接给包目录会报 "unsupported plugin format"。
- 脚本在 `sfzmap.json` 旁边写 `env.json`（Surge、音色目录、sfizz_render 的位置），`render.py` 自动读取；也可以用环境变量 `SURGE_VST3`、`SURGE_PATCHES`、`SFIZZ_RENDER` 覆盖。
- 在 Git Bash 里手动跑 `git sparse-checkout` 时，以 `/` 开头的路径会被改写成 `C:/Program Files/Git/...`，结果一个文件都检不出来；要先 `export MSYS_NO_PATHCONV=1`。
- Windows 上运行时加 `PYTHONIOENCODING=utf-8`，否则脚本打印的中文是乱码。
- 本机实测（2026-10-09）：猫样片总谱 12 个声部全部渲染成功，成品 -16.0 LUFS。
- 环境坏了、临时不可用时，先用程序合成的音乐（Karplus-Strong 拨弦、正弦和弦垫音、FM 钟声，见 ink-sticker 示例），并告诉用户。

有旁白时，把 `music_final.wav` 当作 `--bgm` 交给下面的 `mix_audio.py`，和旁白一起做闪避和响度。

**写谱的规则**

- **先定速度和起点，让关键时刻落在拍点上**：从分镜和 `audio/<语言>/shots.json` 里挑出最重要的 2–4 个时刻（转折、撞击、标题出现），选一个速度和起始偏移，使它们都落在拍上。差一点的，改动画的时间去对音乐（两边共用一条时间轴，改哪边都行）。两种语言的分镜时长不同，各写一份速度/偏移，或者让关键时刻按各自的 shots.json 落拍。
- **结构跟着故事走**：每个段落对应一段剧情，在 PROJECT.md 的色彩剧本旁边写下"这一段用什么声部、什么和弦、往哪推"。
- **层层叠出推进感**：铺底一小节一个和弦 → 钢琴一拍两个音 → 琶音一拍四个音；要安静时整组声部一起停。
- **灾难题材的常用走向**：日常段用轻快的小调拨弦 → 征兆出现时音乐跑调、变慢（音高往下滑几个百分点）→ 事件前一刻全部骤停（留 0.1–0.3 秒真空）→ 事件本身交给音效 → 余波用低音长音和弦乐 → 结尾一个钢琴单音或钟声。
- **去机器味**：每个音的力度随机 ±6，时间随机 ±0.02 拍；但卡画面的音不加时间抖动。
- **弦乐要渐强进入**：采样原本起音只有几毫秒，SFZ 里把 `ampeg_attack` 改到约 0.28 秒，再用 CC11 在每个和弦上做渐强。
- **音效也用乐器演奏**（卡通片的 Mickey-Mousing 手法，适合墨线贴纸、扁平插画）：松手"叮"用拨弦 + 木琴、翻身"嗖"用木琴上行三连音、落地用定音鼓 + 对镲、闪光用钢片琴。写在同一份总谱里，天然对齐。
- **垫在旁白下面时**：避开旁白的频段和节奏，旋律乐器少用，铺底和琶音为主；说话密集的段落减声部。

**踩过的坑**

- **VSCO-2 只有 wav，没有 SFZ**：用 `sfz_gen.py` 按文件名生成。它的文件名用"C3 = 中央 C"的记法，实测每个采样都比文件名高一个八度，脚本已经统一加了 12 个半音。
- **pedalboard 不能直接读 Surge 的 .fxp**：Surge 的插件状态就是 .fxp 去掉前 60 字节的文件头，`surge_state.py` 负责替换；换音色后要先空跑一次，Surge 在下一次处理时才真正换上。
- **sfizz 输出有直流偏移**（约 -90 dBFS）：录得轻的声部要加 40 dB 以上的增益，不处理会变成持续的低噪。`mix.py` 在每轨最前面加了 30 Hz 高通和噪声门。
- **打击乐采样开头可能有静音**：有的录音在击打前空了 0.1 秒，"砰"会比画面晚两三帧。`sfz_gen.py` 会自动用 `offset` 跳过。
- **检查对齐不能靠听感**：用起音检测量出每个关键音的时刻，和画面事件的时间比，误差要小于一帧（30fps 时 33 毫秒，60fps 时 17 毫秒）。

## 混音：`scripts/mix_audio.py`

```bash
python <skill目录>/scripts/mix_audio.py \
  --voice audio/zh/narration.wav --bgm audio/music_final.wav --sfx audio/sfx.wav \
  --out audio/zh/mix.wav --video out/<片名>_zh_raw.mp4 --final out/<片名>_zh.mp4
```

- 音乐用旁白做**侧链压缩**：有人说话时自动压低约 10 dB，停顿处约 0.6 秒内回升。压得不够或太狠时调 `--duck`、`--bgm-gain`。
- 音效不参与闪避，用 `--sfx-gain` 整体调；个别音效的轻重在 `sfx_events.json` 的 `gain` 里调。
- 两遍 loudnorm，统一到 **-14 LUFS、真峰值 -1.5 dBTP**（YouTube、B 站、抖音都适用），脚本打印混音前后的响度，写进检查报告。
- 中文版、英文版各混一次（旁白不同，音乐和音效共用）。
- 只有 ffmpeg 就能跑。没有旁白的样片直接把音乐和音效相加后做 loudnorm 即可。

## 检查（逐段，不能只看平均值）

- **逐秒电平**：每秒打印峰值和 RMS，找出意外的静音段和爆音段（"突然安静"是设计出来的，要能对上画面）。
- 每句旁白的时间窗里都有人声，且音乐没有盖过旁白（用 volumedetect 量旁白窗口内外的音量差）。
- 每个跟动作走的音效和画面对上：抽查成片对应帧，或用起音检测量误差（< 1 帧）。
- 成片综合响度在目标值 ±1 LU 内，真峰值不超过 -1 dBTP。
- 用到的外部音乐、环境声素材都记在 NOTES.md，需要署名的进 PUBLISH.md。
- 声音要请用户戴耳机听一遍：电平检查只能保证"有声音、不爆"，听感好不好要人来判断。
