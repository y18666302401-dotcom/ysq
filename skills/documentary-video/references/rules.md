# 通用规则（所有画风、所有题材都适用）

## 1. 画面比例：信息画面与场景画面

- **信息画面**（地图、图表、数据卡片、时间线）只占全片的 30%–40%。
- **场景画面**（人物、地点、事件现场、实物）占大部分。
- 信息画面每次只出现一小段，不连续超过两句旁白；每次回来都要带一层新信息（新路线、新数字、新标记）。

原因：信息画面负责讲清逻辑，场景画面负责让观众感受到处境。连续看示意图，观众会出戏。

电影化画风（默认画风，以及柔光动画）里，信息画面不做成独立的平面图，而是画在场景里的纸、墙、物件上，或把场景"切开"展示（见 styles/hand-drawn-cinematic.md 的"示意画面电影化"）。

## 2. 动效：要做动画，不要做 PPT

**任意暂停测试**：随便在哪一帧暂停，画面里都应该有东西"正在运动的半途中"。如果暂停下来像一张排好版的幻灯片，就不合格。

每个镜头同时具备三层运动：
- **主运动**：故事要观众看的动作
- **次级运动**：主运动带出的连锁反应（被撞后摇晃、被拉后回弹、灯被震得摆动）
- **环境运动**：一直存在的背景动态（风、雪、灰尘、光线微闪）

**物理因果**：元素出场要有原因，不用"淡入""弹出"。东西被推进来、掉下来、被钉上、被拉过来；有重量、惯性、碰撞和回弹。摆动、滑动、坠落尽量用简单的物理计算预先算好（固定步长积分，结果按时间查表），保证确定性。

**镜头衔接**：场景切换要有物理上的动机（镜头推进某个物体后进入下一个场景、画面被翻页、物件变成下一场景的元素），少用交叉淡化。

**招牌镜头**：每集挑 1–3 个最关键的时刻（高潮、转折）做成重点动画，其他镜头保持简洁。先做一个招牌镜头给用户确认动画质感，再全面铺开。

**冲击感**：重要的冲击（撞击、盖章、断裂）时画面轻微震动，配合对应音效。

## 3. 字幕：重点信息标色

按信息类型固定颜色，全片统一。具体颜色在本期视觉设定里定（见 visual-decisions.md），下表是默认值：

| 信息类型 | 默认颜色 |
|---|---|
| 时间日期 | 琥珀金 #E8B04A |
| 地点 | 冰蓝 #8EC5E8 |
| 数字和关键转折 | 红色 #E5483A |
| 人名 | 薄荷绿 #9FE3B4，略大一号（1.08 倍） |
| 其余文字 | 米白 #F3EBDD |

- 标色是本期配色的一部分，不是额外加的颜色。画风限定了配色数量时（如扁平插画每期 6–9 种），四类标色要从本期配色里选：可以把默认色直接纳入本期配色，也可以改用配色里最接近的颜色，但四类之间必须一眼能区分，并且在深浅背景上都清晰。
- **标色必须真的落到字幕上**（用户 2026-10-12 指出：第 4、5 期字幕去了标点，却几乎没有标色）。原因是旧做法只给 cues.json 里的"动作提示词"标色，绝大多数人名、地名、年份、数字都没进表。现在统一这样做：
  - 阶段 2 写完脚本，同时写项目根目录的 `highlights.json`（两种语言各一份词表，分 name / place / date / num / key 五类，key = 关键转折，用数字的红色）。人名、地名、关键转折只能手写；年份、朝代、世纪、带单位的数字由 `scripts/subtitles.js` 自动识别，手写的优先。同一个人名、地名只在全片前 2 次出现时标色，避免主角名每行都变色。
  - 字幕一律用 `scripts/subtitles.js` 断行、去标点、标色、绘制，不在每期的动画代码里另写一套。
  - 渲染前每种语言跑一次自查 `node scripts/subtitles.js <项目根目录> zh|en`：它逐行打印字幕并用 [类型:词] 标出重点词。**标色行少于 40%**、highlights.json 里有词没出现在字幕中、或残留标点，都要先修好再渲染。成片抽帧时专门看一帧有标色的字幕。
- 每句最多标两三处，不要满屏彩色（subtitles.js 每行最多 3 处）。
- 重点词在读到它的那一刻才变色并轻轻放大回弹（用词级时间戳对齐）。
- 画面中的同类信息用同样的颜色（地图上的地名用冰蓝、数据卡片的数字用红色），和字幕呼应。
- 竖屏字幕放在主画面下方、底部安全区之上，最多两行，字号够大；文字带深色描边保证在任何背景上都清晰。
- **字幕不显示标点符号**（用户 2026-10-11 要求，两种语言都适用）：引号、书名号、括号直接去掉；句中的逗号、顿号、冒号、分号、破折号换成一个空格（中文用全角空格）；句末的句号、问号、感叹号不显示。英文保留单词里的撇号和连字符（Modena's、well-known）。只改字幕的显示，脚本和配音文本照常带标点。

## 4. 调色与质感：不要"淡"

画面发灰、偏亮、颜色不浓，观众会觉得"淡、没质感"。默认要求：
- **黑位压低**：画面最暗处接近纯黑，不要发灰。
- **整体偏沉**：平均亮度不要过高，留出暗部。
- **颜色要浓**：饱和度明显高于"安全的灰调"，暖色要暖、冷色要冷。
- **有方向的光**：主光从一侧来，画面中心亮、四周迅速变暗；物体有投影，前后层次分明。
- **质感叠加**：纸纹、颗粒、暗角按画风适量叠加。

可以用这几个指标自查（抽帧计算）：最暗处 2% 分位亮度 ≤ 0.03，平均饱和度不低于 0.4。画风文件另有实测指标时以画风文件为准（柔光动画见 glow.md 第 7 节；手绘 + 电影化 2.5D 见该文件第 10 节）。调色只作用于画面，字幕和信息条保持清晰。

"整体偏沉"不等于"整体压暗"：夜景、灾难后的场景也要有看得见的光源和足够的明暗对比，主体能从背景里分出来。

**夜景（所有画风通用）**：不要给整幅画叠一层灰 / 紫来"变成夜里"。做法是：每种颜色换成它自己的夜色（偏冷偏暗，但保留色相差和明暗差）；画面里至少一个看得见的暖光源（灯、火、窗），它照到的地方、人物朝它的一侧明显偏暖；人物背光一侧用冷色轮廓光（月光）从暗背景里分出来。具体实现见各画风文件（墨线贴纸：`night.js`；手绘电影化：第 8 节"夜景用光"；柔光动画：内边光）。

## 5. 装饰元素必须有含义

画面里的每个元素都要能回答"它在故事里是什么"。不要放没有故事含义的装饰（例如为了好看在人物身后放一个红色大圆，观众会去猜它是太阳还是什么）。人物背景应该是故事世界的一部分：当地的环境、相关的物件、当时的光线。

## 6. 人物

- 人物外观自由设计，不需要和真人长得像，也不查肖像：事件和身份是真实的，长相可以是虚构的。按故事里的身份、时代、性格和报道提到的特征设计，有辨识度即可。
- 每个重要人物的造型在本期视觉设定里定一次，全片复用同一份造型代码，保证前后一致。
- 人物第一次出场时配名牌：真实姓名、身份、生卒年。
- 有大幅动作的人物用简化造型或剪影；表情和细节留给特写。
- **人物的画法（所有画风通用）**：
  - 默认 **3/4 侧身**，不画纯侧身：两个肩膀都看得到，四肢分别从身体两侧长出来，脸上远侧的眼睛压窄、鼻子在两眼之间偏远侧。
  - **不逐部件描边**：整个人物合成一个剪影只描一圈外轮廓，内部只在真正有前后遮挡的地方补细的、两头收尖的内线；肩、肘、胯、脖子处不能出现一圈圆形接缝。
  - **四肢是连续的锥形**：根部粗、关节处收窄、末端最细，带肌肉起伏，不是粗细均匀的"面条"。
  - **五官**：眼睛不要画成粗圆圈（会像眼镜），两眼要分开；闭眼画成弧线；表情主要靠眉毛和眼皮；嘴按透视画，不要悬空的椭圆。
  - **耳朵**：侧面 / 3/4 侧面的耳朵画成"C"形，不要画成一个椭圆或圆球。前缘贴着脸颊、几乎是直的；后缘向后鼓出，上宽下窄收成耳垂；高度约从眉毛到鼻底；里面一块 C 形耳窝暗面 + 一道沿耳轮内沿的弧线（可再加一小笔耳屏）。
  - **手**：画成哆啦A梦式的圆手掌，不画手指、不画拇指。握东西时圆手掌盖在物件上；松手、挥手靠整只手的位移和速度线表现，不靠张开手指。
  - 墨线贴纸的完整实现见 `scripts/examples/ink-sticker/char34.js`；其他画风按同样的原则画。
- **动作要自然**（做法和示例见 `scripts/examples/character-rig/`）：
  - 用骨架 + 两节 IK：给出脚要踩、手要撑的位置，膝盖和手肘自己算。**脚落地后不许滑**，走路是一只脚踩住、另一只脚抬起来迈出去，不是整个人平移。
  - 用关键姿势表演，不用匀速插值：每个动作前先蓄力（起身前先往下沉、前倾），动作带一点过冲再落回，倒地越来越快、落地后有回弹和镜头震动。
  - 起床、下床、站起、迈步、腿软、倒地这类动作分成清楚的几个姿势，每个姿势都要符合身体结构（坐起靠手肘撑、站起靠腿蹬）；不要让人整体绕胯部像木板一样转。
  - 躺着的人侧躺、脸颊贴枕头朝向观众；不要把头转 90 度让脸朝天花板（侧面看五官会糊成一团）。被子要盖住身体，不能让身体画在被子上面。
  - 姿势按一拍二（12 张/秒）取样，镜头按 24 帧平滑运动（画风文件另有规定的按画风：墨线贴纸 60fps，动作逐帧平滑、只有线条抖动保持 12 次/秒）。
  - 做完抽连续帧（每 0.15 秒一张）排成一条看动作，比只看几张关键帧更容易发现滑步、穿模、僵硬。
- 不丑化、不恶搞真实人物。

## 7. 声音

- 每集至少包含：旁白、背景音乐、环境声、关键动作音效。
- 背景在旁白出现时自动压低（说话时背景比旁白低 9 dB 以上），用 `scripts/mix_audio.py` 的侧链闪避实现，成片统一到 -14 LUFS。
- 高潮处可以用"突然安静"代替加大音量。
- 混音后逐段检查：逐秒电平、每句旁白的时间窗里都确实有人声，峰值不爆音。
- 动作音效程序合成，时间点由动画导出；背景音乐默认代码编曲；环境声能合成就合成，否则用 CC0 素材。AI 生成的音乐、音效要先征得用户同意。需要署名的记进 PUBLISH.md。详见 audio.md。
