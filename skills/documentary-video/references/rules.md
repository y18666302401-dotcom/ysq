# 通用规则（所有画风、所有题材都适用）

## 1. 画面比例：信息画面与场景画面

- **信息画面**（地图、图表、数据卡片、时间线）只占全片的 30%–40%。
- **场景画面**（人物、地点、事件现场、实物）占大部分。
- 信息画面每次只出现一小段，不连续超过两句旁白；每次回来都要带一层新信息（新路线、新数字、新标记）。

原因：信息画面负责讲清逻辑，场景画面负责让观众感受到处境。连续看示意图，观众会出戏。

## 2. 动效：要做动画，不要做 PPT

**任意暂停测试**：随便在哪一帧暂停，画面里都应该有东西"正在运动的半途中"。如果暂停下来像一张排好版的幻灯片，就不合格。

每个镜头同时具备三层运动：
- **主运动**：故事要观众看的动作
- **次级运动**：主运动带出的连锁反应（被撞后摇晃、被拉后回弹、灯被震得摆动）
- **环境运动**：一直存在的背景动态（风、雪、灰尘、光线微闪）

**物理因果**：元素出场要有原因，不用"淡入""弹出"。东西被推进来、掉下来、被钉上、被拉过来；有重量、惯性、碰撞和回弹。摆动、滑动、坠落尽量用简单的物理计算预先算好（固定步长积分，结果按时间查表），保证确定性。

**镜头衔接**：场景切换要有物理上的动机（镜头推进某个物体后进入下一个场景、画面被翻页、物件变成下一场景的元素），少用交叉淡化。

**招牌镜头**：每集挑 1–3 个最关键的时刻（高潮、转折）做成重点动画，其他镜头保持简洁。先做一个招牌镜头给用户确认动画质感，再全面铺开。

**冲击感**：重要的冲击（撞击、盖章、断裂）时画面轻微震动，配合对应音效。

## 3. 字幕：重点信息标色

按信息类型固定颜色，全片统一：

| 信息类型 | 颜色 | 
|---|---|
| 时间日期 | 琥珀金 #E8B04A |
| 地点 | 冰蓝 #8EC5E8 |
| 数字和关键转折 | 红色 #E5483A |
| 人名 | 白色加粗、略大 |
| 其余文字 | 米白 #F3EBDD |

- 每句最多标两三处，不要满屏彩色。
- 重点词在读到它的那一刻才变色并轻轻放大回弹（用词级时间戳对齐）。
- 画面中的同类信息用同样的颜色（地图上的地名用冰蓝、数据卡片的数字用红色），和字幕呼应。
- 竖屏字幕放在主画面下方、底部安全区之上，最多两行，字号够大；文字带深色描边保证在任何背景上都清晰。

## 4. 调色与质感：不要"淡"

画面发灰、偏亮、颜色不浓，观众会觉得"淡、没质感"。默认要求：
- **黑位压低**：画面最暗处接近纯黑，不要发灰。
- **整体偏沉**：平均亮度不要过高，留出暗部。
- **颜色要浓**：饱和度明显高于"安全的灰调"，暖色要暖、冷色要冷。
- **有方向的光**：主光从一侧来，画面中心亮、四周迅速变暗；物体有投影，前后层次分明。
- **质感叠加**：纸纹、颗粒、暗角按画风适量叠加。

可以用这几个指标自查（抽帧计算）：最暗处 2% 分位亮度 ≤ 0.03，平均饱和度不低于 0.4。调色只作用于画面，字幕和信息条保持清晰。

## 5. 装饰元素必须有含义

画面里的每个元素都要能回答"它在故事里是什么"。不要放没有故事含义的装饰（例如为了好看在人物身后放一个红色大圆，观众会去猜它是太阳还是什么）。人物背景应该是故事世界的一部分：当地的环境、相关的物件、当时的光线。

## 6. 人物

- 真实人物的形象只需"形似"：抓住发型、脸型、体格、标志性服装等特征，用所选画风重新设计，不必照着照片描摹。
- 每个重要人物先画一张**角色设计稿**，放在 `characters/`，用户确认后全片复用，保证前后一致。
- 人物第一次出场时配名牌：真实姓名、身份、生卒年。
- 有大幅动作的人物用简化造型或剪影；表情和细节留给特写。
- **画成一个整体，不要拼几何体**：同一层的部件只描一次合并轮廓，四肢从身体里长出来（关节处边线淡出），四肢和尾巴有粗细变化，头和身体不用正圆、椭圆。做法、工具和自查清单见 `references/characters.md`，工具库是 `scripts/character_kit.js`。剪影也适用这一条。
- 不丑化、不恶搞真实人物。

## 7. 声音

- 每集至少包含：旁白、背景音乐、环境声、关键动作音效。
- 背景在旁白出现时自动压低（说话时背景比旁白低 9 dB 以上），用 `scripts/mix_audio.py` 的侧链闪避实现，成片统一到 -14 LUFS。
- 高潮处可以用"突然安静"代替加大音量。
- 混音后逐段检查：每句旁白的时间窗里都确实有人声，峰值不爆音。
- 动作音效程序合成；环境声用 CC0 素材；背景音乐由用户在 Lyria 3、免版税曲库、程序合成之间选。所有外部素材登记来源。详见 audio.md。
