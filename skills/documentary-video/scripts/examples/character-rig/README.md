# 示例：人物骨架与表演（让动作自然）

用户确认过的人物动作做法。`rig.js` 是骨架和关键姿势表演；它画图用的是 `toon.js` 的函数（`shape / noodle / ell`），用在手绘画风时把这几个函数换成 `fine-hand/brush.js` 的 `wash + brush` 即可，骨架和表演逻辑不变。一个典型的表演段落可以这样拆关键姿势：躺着 → 睁眼、眨眼、眼珠转向目标 → 先往下一沉（蓄力）→ 手肘撑起 → 掀被、两腿甩到床边坐起 → 前倾蓄力 → 站起（轻微过冲）→ 迈步（一只脚抬起、落下）→ 腿软 → 跪倒 → 扑倒（加速）→ 落地回弹、镜头震动。

- **两节 IK**：`R.ik(根部, 目标, 长1, 长2, 偏向)`。腿给"脚要踩的位置"、手给"手要到的位置"，膝盖和手肘自己算出来 → 脚踩住地面不滑、手撑住床。
- **关键姿势轨道**：`R.track([[时间, 姿势, 缓动], ...])`，姿势只写变化的字段（髋部位置、脊柱角度、头的角度、两脚两手的目标、表情），其余沿用上一个。缓动可选 `io / out / in / back（轻微过冲）`。
- **视线**：`face.gaze` 写世界坐标里要看的点，瞳孔方向自动换算。
- 按旁白时长伸缩：设计时用中文版时长写关键帧时间，`s = 本语言分镜时长 / 设计时长` 统一缩放。

表演要点见 `references/rules.md` 的"人物"一节。
