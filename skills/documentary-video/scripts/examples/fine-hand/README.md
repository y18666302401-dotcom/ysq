# 示例：细腻手绘画法（默认画风的画法升级）

用户确认过的细腻手绘画法：在逐帧手绘的基础上，把画线、上色、排线都换成更像真手绘的做法。对比图 `对比_旧画法vs细腻画法.png`（左旧右新），参考帧 `参考帧_夜里的村子.png`。

| 文件 | 作用 |
|---|---|
| `brush.js` | **画法引擎（独立，可直接用）**。`const B = require('./brush')({ S, createCanvas })`，S 为 `{ K: 第几张画, Z: 当前图层缩放 }` |

`brush.js` 的四个函数：

- `brush(ctx, pts, { w, col, closed, smooth, taper, press })`：有笔压的线条。起笔轻、中段重、收笔尖；闭合形状背光一侧（右下）自动加粗；每张画换一组低频噪声，线条位置和粗细都有细微差别，但形状连贯——这就是"每张都重新画"的感觉。
- `line(ctx, pts, opts)`：同上，偶尔在旁边补一笔细线（画家修线的痕迹）。
- `wash(ctx, pts, col, { edge, edgeA, blot, gran })`：水彩式上色。颜料在边缘积色、色面有几块深浅不匀、叠颗粒纹理；色块和线条错位 1–3 像素。
- `hatchForm(ctx, pts, { ang, sp, depth, cross, curve, all })`：顺着形体的排线。默认只排在背光一侧（把形状往光源方向挪 `depth`，挪不到的部分就是阴影）；`cross: 1` 在更深处叠交叉排线；`curve` 让排线顺着圆柱、肚子这类曲面弯；`all: true` 整块排线（用于整面背光的侧墙）。

组织一个布景的写法：远景（天空、云、远山）、中景（山坡、远处的小物件，按距离缩小、减少细节）、主体（主要建筑和物件，细节画满）、前景（只在边缘的一两个剪影）分别写成函数；每个物件按"wash 上色 → hatchForm 背光排线 → 细节（纹理、裂纹、木纹）→ brush 描边 → 受光边一笔亮线"的顺序画。

已有项目可以在引擎里一次切换：把通用的 `ink / fill / hatch` 改成调用 `brush / wash / hatchForm`（alpha < 1 的半透明填充、虚线保留旧画法），整片的画法就升级了，再逐个布景补细节。
